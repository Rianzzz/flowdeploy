FlowDeploy criação de WhatsApp Flows sem Postman

Criar flow

Dê um nome para o flow. Ele será criado na categoria OTHER automaticamente.

Colar JSON

Cole aqui o JSON com as telas do flow. Dois formatos são aceitos:
1) Só o conteúdo das telas: { "screens": [...], "version": "7.3" }
2) O comando completo copiado do Postman (com id, to, resource etc.) — o app extrai as telas automaticamente de dentro de resource.

Publicar flow

Publica o flow identificado pelo ID informado na etapa 1, tornando as telas enviadas na etapa 2 ativas.

Consultar flow

Busca e exibe os dados/status atuais do flow, incluindo o link de pré-visualização quando disponível.

Configurações

Esses dados ficam salvos só neste navegador (nunca no servidor) e são enviados a cada chamada pra API do Blip. Se estiver usando o app em outro dispositivo ou navegador, precisa configurar de novo lá.
